# DataSphere Meridian Design System

This redesign keeps the existing DataSphere application structure and Supabase workflows while changing the presentation layer toward an institutional learning workspace.

## Visual direction
- Calm academic interface rather than AI/SaaS styling.
- Distinctive palette: mulberry ink, kelp green, warm ochre, paper and clay.
- Light workspace with restrained borders and almost no decorative shadows.
- Lists, rows, tables and hierarchy are preferred over nested cards.
- Rounded corners are functional and restrained; large pill/card treatments are avoided.
- Colour is semantic: green for progress/action, ochre for attention, clay/red for risk.

## Interaction direction
- Primary actions are visible without making every element a button.
- Course and assessment workflows remain data-driven.
- Navigation is grouped by learner task: Learn, Assess, Connect, Develop.
- Administration receives a separate institutional navigation layer.
- Mobile navigation becomes a drawer rather than a shrunken desktop sidebar.
- Focus states and reduced-motion support are included globally.

## Responsive direction
- Desktop uses a persistent institutional sidebar.
- Tablet uses a collapsible sidebar while retaining full-width content.
- Mobile uses a compact top-level workspace and navigation drawer.
- Long lists remain scrollable and readable rather than being squeezed into dense card grids.

## UX references
The direction was informed by current LMS UX work from Canvas, Blackboard and Moodle: action-oriented dashboards, fewer navigation interruptions, full-page learning contexts, reusable components, consistency and accessibility.
